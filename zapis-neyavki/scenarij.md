# Рилс «Неявки клиентов» — сценарий v1 (2026-10-14)

Метод 3 (HyperFrames, графика кодом) + живой B-roll Pexels/Pixabay. Без Gemini/Veo.
Формат 9:16, ~36 с. Голос: клон islam.devai-2 (одна озвучка после «да»). Без музыки.

## Чья боль
Салоны, барбершопы, клиники, автосервисы, репетиторы. Администратор вручную напоминает
о записи, половина не отвечает, неявка = пустое окно, которое уже не продать.
Закрываем: бот напоминает сам (за 24 ч и за 2 ч), кнопки «Приду / Перенести»,
освободившееся окно уходит людям из очереди.

## Подпись (≤500, 851 симв.)
Клиент записался. И не пришёл.

А пустое окно уже никому не продать.

Знакомо салонам, клиникам, автосервисам, репетиторам:
→ администратор каждый вечер пишет десятки «напоминаем, завтра в 15:00»
→ половина молчит
→ об отмене узнаёшь, когда клиента уже ждут

Бот делает это сам: напоминает за сутки и за 2 часа, принимает «Приду / Перенести» и сразу отдаёт свободное окно тем, кто в очереди.

Напиши «ЗАПИСЬ» в директ, пришлю схему такого бота.
