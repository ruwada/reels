# tools/fx — 17 эффектов для рилсов

Шаблоны эффектов по списку @tenfoldmarc «17 video effects claude can create» (разобраны покадрово по его ролику).
Каждый эффект — один файл `effects/NN_имя.py`, общий движок — `fxlib.py`.

```bash
bash tools/fx/setup.sh                      # один раз в новом контейнере
python3 tools/fx/run.py 07                  # демо одного эффекта -> /tmp/fx/out/07_checklist.mp4
python3 tools/fx/run.py all                 # все 17
python3 tools/fx/run.py 07 --preview        # лист из 6 кадров вместо видео
python3 tools/fx/run.py 07 --src my.mp4 --no-label
```

Источник по умолчанию — `/tmp/fx/src1080.mp4` (1080x1920, 30 fps; для демо — рилс 11 «найм»).
Эффекты 05 и 15 берут исходник крупнее (`src_size` 1620x2880), чтобы зум был без потери качества:
подавайте 4K-оригинал. Настройки сегмента и текстов — словарь `DEMO` в каждом файле; время слов
абсолютное (секунды исходника), так шаблон переносится на другой рилс заменой `DEMO`.

## Что внутри движка
- вырезка человека: u2net_human_seg (ONNX, CPU) + guided filter + сглаживание по времени; кэш по кадрам
  в `/tmp/fx/cache` (повторный рендер того же куска не считает маску заново);
- HTML-слои: интерфейсы, тексты и графики рисуются в headless Chromium (`Html.still` / `Html.frames`
  с `window.seek(t)`), шрифты Unbounded, Manrope, Playfair Display, Caveat лежат локально в `fonts/`;
- 3D: `card_quad` + `warp_quad` (поворот карточки с перспективой), зум, зум-блюр, тени, «стекло» (`frost`).
