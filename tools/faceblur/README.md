# faceblur — блюр всех лиц на видео и фото

Сделано для ролика медресе (2026-11-19): дети и взрослые, iPhone 4K HLG, всё вертикальное.
Правило: **ни одно видимое лицо не уходит в монтаж незаблюренным**, затылки и спины не трогаем.

## Быстрый старт
```bash
bash tools/faceblur/setup.sh
tools/faceblur/run_video.sh /path/IMG_0570.MOV work/0570      # ~25 мин на 27 с видео (4 ядра)
python3 tools/faceblur/photos.py src/ work/photos               # фото: первый проход
```

## Как устроено (видео)
1. `det.py` — insightface SCRFD на каждом кадре (30 fps, 1080x1920), порог 0.3.
2. `det.py --pad` — второй проход по кадру с чёрными полями, порог 0.2: лица, обрезанные краем кадра.
   `filt.py` оставляет низкие баллы только у краёв (иначе блюрится еда).
3. `pose.py` — YOLO11x-pose: голова по ключевым точкам, если виден нос или глаз (conf ≥ 0.25).
   Ловит профили и лица, опущенные вниз, которые SCRFD пропускает. Затылки пропускает.
4. `track.py` — склейка в треки, интерполяция дыр до 20 кадров, удержание 8 кадров на концах,
   объединение ±2 кадра.
5. `manual.py` — ручные треки по ключевым кадрам: `manual.json` = `{"video": [{"0":[x0,y0,x1,y1], "20":[...]}]}`
   (координаты 1080x1920, между ключами линейно).
6. `render_blur.py` — эллипс с запасом 60 % по ширине и 75 % по высоте, крупная мозаика + сильный гаусс
   (необратимо), HLG → SDR тонмаппинг.

## Проверка (обязательно, глазами)
- `sheets.py` делает листы по 6 кадров: шаг 15 со сдвигом 0 и 7 (оба листа = каждые 7–8 кадров).
- `strips.py VIDEO A B STEP OUT` — полосы левого и правого края кадра: **детекторы чаще всего
  пропускают пол-лица у края кадра**, смотреть отдельно.
- Пропуск → ключевые кадры в `manual.json` → снова `manual.py` + `render_blur.py`.

## Фото
`photos.py` — тайлы 1×1…4×4, порог 0.25, пишет `boxes.json`. Боксы < 0.5 — смесь лиц и еды:
вырезать сеткой кропов, выбрать глазами настоящие лица в `photos_keep.json`, пропущенные дорисовать
в `photos_extra.json`, затем `photos_apply.py`.

## Чего не делать
- Не доверять одному детектору и одному зелёному прогону: в медресе SCRFD пропустил мужчину
  у края кадра на 300 кадров и профиль мальчика в начале.
- Не класть исходники с лицами в репозиторий (они в .gitignore папок рилсов).
