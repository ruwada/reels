# Копии скиллов для AI-видео

Три скилла, сохранённые владельцем 2026-10-29. Любое AI-видео (кадры Gemini + Veo/Omni) проходит
их по порядку, с согласованием между шагами:

1. `reel-director.md` — биты, таблица кадров, паспорт героя и света
2. `veo-shot-prompter.md` — промпты кадров и видео (адаптеры Veo 3.1 / Omni Flash), чек-лист до трат
3. `reel-sound-edit.md` — звук, паузы, субтитры RU+EN, безопасные зоны

Это копии на случай переноса в другой аккаунт: там их нужно сохранить как настоящие скиллы заново.
Источник — синхронизированные скиллы аккаунта; при расхождении истина в аккаунте.
