# Как поднять такой же проект на другом аккаунте — от начала до конца

Пошаговый порядок. Каждый шаг помечен:

- **👤 ТЫ** — делаешь сам руками: регистрация, оплата, ключи, кнопки в настройках. Агенту туда
  доступа нет, и ключи в чат ему **не вставлять никогда**.
- **🤖 АГЕНТУ** — пишешь эту фразу в чат нового проекта, дальше он делает сам.

Что лежит рядом с этим файлом (папка `instrukcii/novyj-proekt/` в файлах проекта):

| Файл | Что это |
|---|---|
| `NOVYJ-PROEKT-GAJD.md` | этот гайд |
| `pamyat-proekta.zip` | вся память проекта: 64 файла правил, решений и истории |
| `raspisaniya.md` | промпты и время четырёх регулярных задач (сводка, карусели, истории, LinkedIn) |
| `../montazh-vidy.md` | пять видов монтажа и как каждый делается (то же лежит в репозитории рилсов, `docs/MONTAZH-VIDY.md`) |
| `../skills/` | копии трёх скиллов AI-видео |

**Скачай всю папку `instrukcii/` себе на телефон или компьютер до начала** — файлы старого проекта
в новом не видны.

> Если новый проект на **тех же** аккаунтах GitHub, Google, ElevenLabs, Telegram и Metricool,
> шаги 1 и 5 почти целиком пропускаются: нужны только подключения и ключи в новом окружении.

---

## Шаг 1. Регистрации и ключи — 👤 ТЫ

Ключи из этого шага потом вставляются в настройки окружения (шаг 4), **не в чат**.

| Сервис | Где | Что получить | Для чего |
|---|---|---|---|
| **Claude** | claude.ai | тариф с Claude Code в облаке (Max или Pro) | сам проект, треды, агенты |
| **GitHub** | github.com | аккаунт или организация (у нас `ruwada`) | репозитории с инструментами и слайдами |
| **Google** | Google-аккаунт | Google Drive, папка «рилс» с доступом по ссылке | исходники видео без сжатия |
| **Google AI Studio** | aistudio.google.com → Get API key | ключ Gemini + **пополнить предоплату** в разделе Billing (у нас Paid Tier 1, пополнение лирами) | кадры, Veo/Omni-видео, фото для карусели |
| **Pexels** | pexels.com/api | API key (бесплатно) | сток-видео и фото |
| **Pixabay** | pixabay.com/api/docs (после входа ключ на странице) | API key (бесплатно) | второй сток |
| **ElevenLabs** | elevenlabs.io | тариф Starter или выше; API key с правами Text to Speech, Speech to Speech, **Audio Isolation**, Voices (read и write) | клон голоса, очистка звука |
| **Telegram-бот** | @BotFather → `/newbot` | токен бота | отдача тебе тяжёлых файлов, посты в канал |
| **Telegram-канал** | в Telegram | добавить бота в канал **администратором** с правом публиковать | лид-магниты, посты |
| **Metricool** | metricool.com | бренд; подключить YouTube и TikTok (и Instagram, если нужен календарь) | Shorts и TikTok по расписанию |
| **Typefully** | typefully.com | подключить LinkedIn | посты в LinkedIn |

Для Instagram в Metricool аккаунт должен быть профессиональным (Автор или Бизнес).

## Шаг 2. GitHub и репозитории — 👤 ТЫ

1. Открой **https://claude.ai/connect-github** и подключи GitHub-аккаунт.
2. На той же странице установи **Claude GitHub App** на нужные репозитории (или на всю организацию).
3. Репозитории:
   - **Тот же GitHub** — ничего не копируешь, `ruwada/reels` и `ruwada/carousels` уже есть.
   - **Другой GitHub** — заведи два репозитория через **github.com/new/import**, вставив адреса
     `https://github.com/ruwada/reels` и `https://github.com/ruwada/carousels` (оба публичные).
     `carousels` оставь **публичным**: Metricool забирает картинки по прямой ссылке.
4. Сначала смёрджи рабочую ветку рилсов в `main`, иначе в новом проекте окажется старый `main`
   без инструментов:

> 🤖 **АГЕНТУ (в старом проекте):** «Открой PR из ветки `claude/project-thread-549xkf` в `main`
> в ruwada/reels и проверь, что там все инструменты: tools/fx, tools/code-video, quran-02, docs.»

Потом смёрджи этот PR сам кнопкой на GitHub (👤).

## Шаг 3. Проект в Claude — 👤 ТЫ

1. Создай новый проект.
2. **Project settings → Resources** — добавь оба репозитория.
3. **Project settings → Instructions** — вставь текст ниже (это стоячие правила для каждого треда):

```
Проект: контент для Instagram @islam.devai, Threads, YouTube Shorts, TikTok, LinkedIn и Telegram-канала.
Тема: AI и разработка, внедрение AI в бизнес, автоматизация рутины. Пишем по-русски.
Перед работой читай память проекта (MEMORY.md) и docs/MONTAZH-VIDY.md в репозитории reels.
Публикую я сам: готовые файлы присылай документом в мой личный чат с ботом, тексты — в тред.
Ничего не публикуй без моего «да» на конкретный пост.
Халяль: без женщин и харама в кадре, без музыки в рилсах.
Перед любой тратой ElevenLabs или Gemini — спроси, что и примерно сколько.
Готовый тред сворачивай сразу, как работа закончена.
```

## Шаг 4. Окружение: сеть, ключи, скрипт — 👤 ТЫ

Путь: **Project settings → Environment → меню Cloud environment → шестерёнка у выбранного окружения.**

### 4.1 Network access
Уровень **Limited** (в старом приложении — **Custom**), галочку **Allow package managers**
оставить включённой. В **Allowed domains** добавить:

```
github.com
api.github.com
codeload.github.com
objects.githubusercontent.com
raw.githubusercontent.com
drive.google.com
drive.usercontent.google.com
api.pexels.com
videos.pexels.com
images.pexels.com
pixabay.com
cdn.pixabay.com
generativelanguage.googleapis.com
api.elevenlabs.io
api.telegram.org
fonts.googleapis.com
fonts.gstatic.com
api.quran.com
verses.quran.com
api.alquran.cloud
cdn.islamic.network
everyayah.com
mp3quran.net
*.mp3quran.net
```

Без них не работают: скачивание моделей распознавания (github releases), исходники с Drive,
сток, Gemini, голос, бот, шрифты, Коран.

### 4.2 Ключи
В разделе **Network secrets** (в старом приложении — **API credentials**) — ключ привязывается
к хосту, агент его не видит, прокси подставляет сам:

| Хост | Ключ |
|---|---|
| `api.pexels.com` | Pexels API key |
| `generativelanguage.googleapis.com` | Gemini API key (имя переменной `GEMINI_API_KEY`) |
| `api.elevenlabs.io` | ElevenLabs API key |

Как **переменные окружения** (Environment variables):

```
PIXABAY_API_KEY=<ключ Pixabay>
TELEGRAM_BOT_TOKEN=<токен бота>
```

Новые ключи видят только **новые** сессии: после правок открывай новый тред.

### 4.3 Setup script (по желанию)
Ускоряет каждый новый тред: ffmpeg и Python-пакеты ставятся сразу. Скрипт не видит ключей —
им это и не нужно.

```bash
#!/usr/bin/env bash
command -v ffmpeg >/dev/null || { apt-get update -q && apt-get install -y -q ffmpeg; }
python3 -m pip install -q sherpa-onnx numpy pillow playwright onnxruntime opencv-python-headless
```

Тяжёлые модели (GigaAM, Whisper, u2net) и шрифты агент докачивает сам своими `setup.sh`.

## Шаг 5. Коннекторы — 👤 ТЫ

Открой **https://claude.ai/customize/connectors** и подключи:

- **Google Drive** — поиск исходников в папке «рилс»
- **Metricool** — Shorts, TikTok, календарь
- **Typefully** — LinkedIn
- **Crustdata** (по желанию) — разбор лидов

Коннекторы читаются при старте сессии: после подключения открой новый тред.

## Шаг 6. Проверка, что всё подключено

> 🤖 **АГЕНТУ:** «Проверь окружение по шагам 4–5 гайда: сделай по одному маленькому запросу
> к Pexels, Pixabay, Gemini, ElevenLabs (список голосов), Telegram (getMe), Google Drive, Metricool
> и Typefully, скачай одну модель с GitHub и один аят с quran.com. Напиши таблицей, что работает,
> а что нет и где это поправить.»

Что агент найдёт закрытым, правишь ты (👤) по его подсказке.

## Шаг 7. Память проекта

1. 👤 Загрузи `pamyat-proekta.zip` в чат нового проекта.
2. 🤖 **АГЕНТУ:** «Это память старого проекта. Разверни все файлы из архива в память этого
   проекта как есть, с MEMORY.md. Потом пройди по ним и пометь, что устарело для нового
   аккаунта: id чата с ботом, бренд Metricool, набор Typefully, id расписаний и тредов, voice_id
   ElevenLabs. Покажи мне список, что поменять.»

## Шаг 8. Файлы проекта

В старом проекте лежат вещи, на которые опирается работа: твои референсы лица и студийные фото
(`reels/smeshnye/referensy`, `foto`, `foto-2`, `referensy-2`), скрипт фото для каруселей

(`telegram-digest/ideas-log.md`).

> 🤖 **АГЕНТУ (в старом проекте):** «Собери в один архив из файлов проекта: референсы и фото

> Пришли архив мне в бота.»

👤 Загрузи архив в чат нового проекта.

> 🤖 **АГЕНТУ (в новом проекте):** «Разложи архив в файлы проекта по тем же путям, что в памяти.»

## Шаг 10. Скиллы AI-видео

1. 👤 Загрузи в чат три файла из папки `skills/` (или агент возьмёт их из репозитория,
   `docs/skills/`).
2. 🤖 **АГЕНТУ:** «Предложи мне три скилла из docs/skills: reel-director, veo-shot-prompter,
   reel-sound-edit — тексты без изменений.»
3. 👤 Нажми **Сохранить** на карточке, которую он покажет. Сам агент сохранить скилл не может.

## Шаг 11. Голос

- **Тот же аккаунт ElevenLabs** — голос `islam.devai-2` уже на месте, ничего не делаешь.
- **Новый аккаунт ElevenLabs** — голос надо клонировать заново:

> 🤖 **АГЕНТУ:** «Мне нужен клон моего голоса в новом ElevenLabs. Возьми мои записи рилсов
> из папки «рилс» на Drive, подготовь ~6 минут чистой речи и скажи, сколько это стоит,
> прежде чем создавать клон.»

👤 Скажи «да», потом послушай пробу. Новый voice_id агент запишет в память.

## Шаг 13. Пробный прогон каждого вида монтажа

По одной фразе на вид, чтобы убедиться, что всё на месте (описание видов — `montazh-vidy.md`):

| Вид | 🤖 Фраза агенту |
|---|---|
| Сухой рилс | «Подготовь контейнер (tools/setup.sh) и смонтируй рилс из файла <название> в папке рилс.» 👤 перед этим открой файлу доступ по ссылке |
| 17 эффектов | «Поставь tools/fx и пришли превью эффекта 07 на моём видео.» |
| Видео из кода | «Поставь tools/code-video и отрендери шаблон, пришли лист кадров с безопасными зонами.» |
| Коран | «Сделай пробное видео: сура 103, чтец 92, стиль clean, с проверкой контраста.» |
| AI-видео | «Сделай короткую сторис по скиллам reel-director → veo-shot-prompter → reel-sound-edit, на каждом шаге жди моего да.» |
| Карусель | «Запусти задачу карусели вручную на завтра.» |
